article Exercise Description

Fibonacci Sequence Implementation

Implement three functions that work with the Fibonacci sequence:

1. fibonacci(n)

Return a list of the first n Fibonacci numbers, starting from 0. If n <= 0, return an empty list.

>>> fibonacci(7)
[0, 1, 1, 2, 3, 5, 8]

2. fibonacci_recursive(n)

Return the n-th Fibonacci number using recursion. Your solution must handle inputs up to n = 50 within 5 seconds.

>>> fibonacci_recursive(10)
55

3. is_fibonacci(num)

Return True if the given number appears in the Fibonacci sequence, False otherwise.

>>> is_fibonacci(13)
True
>>> is_fibonacci(4)
False

Requirements:

  • All functions must handle edge cases (negative numbers, zero)
  • The recursive solution must be efficient enough for large inputs
  • Include proper type hints

Hints:

  • Look into Python's functools module for optimising recursion
  • A number is a Fibonacci number if and only if one of 5n² + 4 or 5n² - 4 is a perfect square
